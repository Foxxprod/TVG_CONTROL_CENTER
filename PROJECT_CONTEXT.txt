                      edition) / footer.

- buttons_config.py : chargement + VALIDATION de templates.json (erreurs

- data_source.py    : contrat de source de donnees (None par defaut).
- app_config.py / paths.py / app.spec : config machine, chemins, compilation.

Fichiers de donnees : templates.json (catalogue de boutons, commite,
editable aussi depuis le mode edition) / config.json (machine, non commite).
